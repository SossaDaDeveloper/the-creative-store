# Figma Store Clone

This is a recreation of the Figma Store landing page built to practice modern frontend development.

## Preview

This project replicates the playful and bold identity of the original Figma Store website, including:

* Custom layout sections
* Product grid cards
* Large hero visuals
* Clean typography structure
* Bright branded color palette
* Responsive positioning and spacing

## Built With

* React JS
* TypeScript
* Tailwind CSS
* Responsive Design Principles

## What I Practiced

* Recreating real-world UI designs
* Responsive layouts and alignment
* Image handling and card structures
* Visual accuracy from design references

## Purpose of This Project

This project was built as part of my frontend development practice to improve my ability to turn existing UI designs into functional and responsive web experiences.

The focus was on:

* Attention to detail
* Layout replication
* Frontend implementation speed
* Clean component structuring
